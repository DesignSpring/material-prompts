How do I publish my changes?
  1. Click Download updated website.
  2. Extract the downloaded ZIP.
  3. Open your GitHub repository in your usual browser.
  4. Choose Add file → Upload files. Upload the extracted files and the assets folder, then commit the changes.
  5. GitHub Pages will update after deployment. Reload the website to see your changes.

Upload the editor files too, so the downloadable copy stays up to date. Your unpublished draft stays in this browser. Anyone can open this editor, but only someone with access to your GitHub repository can publish changes.
